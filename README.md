# 🛒 Product Research List

### Bangladesh Online Reselling Business

A simple and responsive product research website created to organize potential products for starting a small online reselling business in Bangladesh.

The website presents researched product opportunities in a clean card-based layout with estimated buying prices, selling prices, starting quantities, categories, and priority ratings.

## 📌 Project Overview

The purpose of this project is to create a simple product research dashboard where potential reselling products can be viewed and compared easily.

Each product contains:

- 📦 Product name
- 🏷️ Product category
- 💰 Estimated buying price
- 💵 Estimated selling price
- 📊 Suggested starting quantity
- ⭐ Priority rating
- 🔢 Product number

The current list contains **25 potential products** across different categories.

---

## ✨ Features

### 🛍️ Product Research

The website displays a collection of potential products suitable for online reselling.

### 💰 Price Comparison

Each product shows an estimated:

- Buy Price
- Sell Price

This makes it easier to understand the possible selling margin.

### 📦 Starting Quantity

Each product includes a suggested starting quantity to help estimate initial inventory requirements.

### ⭐ Priority Rating

Products are given a priority rating using a five-star system.

### 📱 Responsive Design

The website is designed to work across:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

### 🎨 Clean UI

The design uses a simple:

- Black
- White
- Gold

color combination with responsive product cards and hover effects.
